第4章　請求・料金・サポート

20問・答えと解説つき（問題を読んでから「答えと解説を見る」を押す）

第4章　問1

短期間だけ使う検証用サーバーで、いつ止めるかまだ決まっておらず、途中で中断されては困る。最も適したEC2の購入オプションはどれ？

  1. ア　リザーブドインスタンス（3年）
  2. イ　スポットインスタンス
  3. ウ　オンデマンドインスタンス
  4. エ　Dedicated Hosts
答えと解説を見る

正解：ウ　オンデマンドインスタンス

オンデマンドインスタンスは長期の契約なしで、使った分だけ支払い、いつでも止められるので短期で先が読めない用途に向く。リザーブドインスタンスは1年か3年の契約が前提で、スポットインスタンスはAWSの都合で中断されることがある。

第4章　問2

ある会社は、社内の基幹システムを今後3年間、同じインスタンスタイプで24時間動かし続ける予定である。コストを最も抑えられる購入オプションはどれ？

  1. ア　3年のStandardリザーブドインスタンス
  2. イ　オンデマンドインスタンス
  3. ウ　スポットインスタンス
  4. エ　On-Demand Capacity Reservations
答えと解説を見る

正解：ア　3年のStandardリザーブドインスタンス

使い方が長期間変わらないなら、3年のStandardリザーブドインスタンスで大きな割引を受けられる。オンデマンドは割引がなく、スポットは中断されうるので止められない基幹システムには向かない。Capacity Reservationsは容量を確保する仕組みで、それ自体は割引ではない。

第4章　問3

Convertibleリザーブドインスタンスの特徴として正しいものはどれ？

  1. ア　契約期間中にインスタンスファミリーなどを別のものに交換できる
  2. イ　Standardリザーブドインスタンスより割引率が必ず高い
  3. ウ　契約期間を1か月単位で選べる
  4. エ　AWSの都合で2分前の通知とともに中断されることがある
答えと解説を見る

正解：ア　契約期間中にインスタンスファミリーなどを別のものに交換できる

Convertibleリザーブドインスタンスは、契約期間中にインスタンスファミリーやOSなどが異なるものへ交換できる。その柔軟さの代わりに、割引率はふつうStandardより低い。期間は1年か3年で、中断があるのはスポットインスタンス。

第4章　問4

リザーブドインスタンスの支払い方法のうち、同じ条件で比べたとき割引が最も大きくなるものはどれ？

  1. ア　前払いなし（No Upfront）
  2. イ　一部前払い（Partial Upfront）
  3. ウ　全額前払い（All Upfront）
  4. エ　毎月オンデマンド料金で支払う
答えと解説を見る

正解：ウ　全額前払い（All Upfront）

リザーブドインスタンスは、前払いの額が多いほど割引が大きくなり、全額前払いが最も安い。前払いなしは初期費用がかからない代わりに割引が小さい。オンデマンド料金での支払いは割引の仕組みではない。

第4章　問5

リザーブドインスタンスを特定のアベイラビリティーゾーンを指定して購入する（ゾーン）場合に得られる、リージョン指定にはない特徴はどれ？

  1. ア　そのAZでのインスタンスの容量が予約される
  2. イ　割引がすべてのリージョンに適用される
  3. ウ　AWS Lambdaの料金にも割引が適用される
  4. エ　契約期間中にいつでも無料で解約できる
答えと解説を見る

正解：ア　そのAZでのインスタンスの容量が予約される

AZを指定したリザーブドインスタンスは、割引に加えてそのAZでの容量予約が付く。リージョン指定のものは容量予約がない代わりに、リージョン内のどのAZでも割引が使える柔軟さがある。Lambdaへの適用や他リージョンへの適用はない。

第4章　問6

ある会社は、EC2のほかにAWS FargateとAWS Lambdaも使っており、今後インスタンスファミリーやリージョンを変えるかもしれない。割引を受けつつ柔軟性を最も保てるものはどれ？

  1. ア　EC2 Instance Savings Plans
  2. イ　Compute Savings Plans
  3. ウ　Standardリザーブドインスタンス
  4. エ　Dedicated Hosts
答えと解説を見る

正解：イ　Compute Savings Plans

Compute Savings Plansは、インスタンスファミリー・リージョン・OSに関係なくEC2に適用され、FargateとLambdaにも適用される。EC2 Instance Savings Plansは特定のリージョンの特定のインスタンスファミリーに限られ、Standardリザーブドインスタンスも条件が固定される。

第4章　問7

EC2 Instance Savings Plansの説明として正しいものはどれ？

  1. ア　どのリージョンのどのインスタンスファミリーにも適用される
  2. イ　AWS FargateとAWS Lambdaにも適用される
  3. ウ　中断される可能性がある代わりに最大の割引を受けられる
  4. エ　選んだリージョンの特定のインスタンスファミリーに適用され、その範囲内ならサイズやOSを変えても割引が続く
答えと解説を見る

正解：エ　選んだリージョンの特定のインスタンスファミリーに適用され、その範囲内ならサイズやOSを変えても割引が続く

EC2 Instance Savings Plansは、リージョンとインスタンスファミリーを決めて契約し、その中ならサイズ・OS・AZを変えても割引が適用される。範囲が狭い分、Compute Savings Plansより割引が大きい。FargateやLambdaへの適用はCompute Savings Plansの特徴。

第4章　問8

Savings Plansで利用者が約束（コミット）するものはどれ？

  1. ア　特定のEC2インスタンスIDを使い続けること
  2. イ　毎月決まった数のサポートケースを開くこと
  3. ウ　一定量のデータをAWSに保存し続けること
  4. エ　1年または3年の期間、1時間あたり一定の金額分の利用を続けること
答えと解説を見る

正解：エ　1年または3年の期間、1時間あたり一定の金額分の利用を続けること

Savings Plansは、1年か3年の期間、1時間あたりの利用金額（ドル/時）を約束することで割引を受ける仕組み。特定のインスタンスに結び付くものではなく、約束した金額までの利用に割引料金が適用される。

第4章　問9

機械学習チームが、Amazon SageMaker AIのトレーニングや推論の利用料金を長期の約束で下げたい。最も適したものはどれ？

  1. ア　Amazon SageMaker Savings Plans
  2. イ　EC2 Instance Savings Plans
  3. ウ　スポットインスタンスのリクエスト
  4. エ　AWS Budgets
答えと解説を見る

正解：ア　Amazon SageMaker Savings Plans

Amazon SageMaker Savings Plansは、1年か3年の利用金額の約束で、Amazon SageMaker AIの対象となる利用に割引を適用する。EC2 Instance Savings PlansはEC2が対象で、AWS Budgetsは予算の監視をするだけで料金そのものは下げない。

第4章　問10

ある会社は、夜間に大量の画像を変換するバッチ処理を行う。処理は途中で止まっても後からやり直せ、開始時刻にも余裕がある。コストを最も抑えられる購入オプションはどれ？

  1. ア　オンデマンドインスタンス
  2. イ　Dedicated Instances
  3. ウ　3年のConvertibleリザーブドインスタンス
  4. エ　スポットインスタンス
答えと解説を見る

正解：エ　スポットインスタンス

スポットインスタンスはAWSの空き容量を使うため大幅に安く、中断されてもやり直せる処理に向いている。オンデマンドは割引がなく、Dedicated Instancesは専用ハードウェアの分だけ高い。不定期のバッチに3年の契約は合わない。

第4章　問11

スポットインスタンスについて正しい説明はどれ？

  1. ア　一度起動すれば、利用者が止めるまで必ず動き続ける
  2. イ　AWSがその容量を必要とすると、事前の通知のうえで中断されることがある
  3. ウ　1年か3年の契約が必要である
  4. エ　オンデマンドインスタンスより料金が高い
答えと解説を見る

正解：イ　AWSがその容量を必要とすると、事前の通知のうえで中断されることがある

スポットインスタンスは、AWSが容量を必要としたときに2分前の通知のうえで中断されることがある。その代わりオンデマンドより大幅に安く、長期の契約もいらない。

第4章　問12

ある会社は、物理サーバーのソケット数やコア数で数えるソフトウェアのライセンスを、そのままAWSに持ち込みたい。最も適したEC2のオプションはどれ？

  1. ア　Dedicated Hosts
  2. イ　Dedicated Instances
  3. ウ　スポットインスタンス
  4. エ　Compute Savings Plans
答えと解説を見る

正解：ア　Dedicated Hosts

Dedicated Hostsは物理サーバー1台を丸ごと割り当て、ソケットやコアの数が見えるので、サーバー単位のライセンスを持ち込む（BYOL）のに向く。Dedicated Instancesも専用ハードウェアで動くが、物理サーバーの構成は見えず、どのサーバーに置くかも制御できない。

第4章　問13

Dedicated InstancesとDedicated Hostsの違いとして正しいものはどれ？

  1. ア　Dedicated Instancesは他の利用者と同じ物理サーバーを共有する
  2. イ　Dedicated Hostsはスポット価格でしか買えない
  3. ウ　Dedicated Hostsでは物理サーバーが見え、インスタンスをどのサーバーに置くかを制御できる
  4. エ　Dedicated Instancesでは物理サーバーのソケット数を確認してライセンスに使える
答えと解説を見る

正解：ウ　Dedicated Hostsでは物理サーバーが見え、インスタンスをどのサーバーに置くかを制御できる

どちらも他のAWSアカウントとハードウェアを共有しないが、Dedicated Hostsは物理サーバーそのものが利用者に割り当てられ、配置やソケット・コア数を把握できる。Dedicated Instancesは専用ハードウェアで動くだけで、物理サーバーの管理はできない。

第4章　問14

ある会社は、年に一度の大型セールの期間だけ、特定のAZで確実にEC2を起動できるようにしておきたい。長期の契約はしたくない。最も適したものはどれ？

  1. ア　3年のリザーブドインスタンス
  2. イ　On-Demand Capacity Reservations
  3. ウ　スポットインスタンス
  4. エ　EC2 Instance Savings Plans
答えと解説を見る

正解：イ　On-Demand Capacity Reservations

On-Demand Capacity Reservationsは、期間の約束なしに特定のAZで容量を予約でき、不要になれば取り消せる。リザーブドインスタンスやSavings Plansは1年か3年の約束が必要で、スポットインスタンスは起動や継続の保証がない。

第4章　問15

インターネットからAWSへのデータ転送（インバウンド）の料金について、一般的に正しいものはどれ？

  1. ア　転送量に応じて高額の料金がかかる
  2. イ　原則として料金はかからない
  3. ウ　リージョン内の転送より高い
  4. エ　1日の上限を超えると転送できなくなる
答えと解説を見る

正解：イ　原則として料金はかからない

インターネットからAWSに入るデータ転送は、原則として無料。一方でAWSからインターネットへ出ていく転送（アウトバウンド）は、量に応じて料金がかかる。

第4章　問16（2つ選ぶ）

データ転送の料金が一般的に発生するものはどれ？2つ選んで。

  1. ア　Amazon EC2からインターネットへのデータ送信
  2. イ　インターネットからAmazon S3へのアップロード
  3. ウ　東京リージョンから別のリージョンへのデータ転送
  4. エ　AWS Pricing Calculatorで見積もりを作ること
  5. オ　AWS Budgetsのアラートを受け取ること
答えと解説を見る

正解：ア　Amazon EC2からインターネットへのデータ送信
ウ　東京リージョンから別のリージョンへのデータ転送

AWSからインターネットへのアウトバウンド転送と、リージョン間の転送には料金がかかる。インターネットからのインバウンド転送は原則無料。Pricing Calculatorは無料のツールで、データ転送とは関係がない。

第4章　問17

同じリージョン内で、あるAZのEC2インスタンスから別のAZのEC2インスタンスへデータを送る場合の料金について正しいものはどれ？

  1. ア　同じリージョン内なので必ず無料になる
  2. イ　インターネットへの送信と同じ料金体系になる
  3. ウ　AZをまたぐ転送には料金がかかる
  4. エ　AZをまたぐ転送はできない
答えと解説を見る

正解：ウ　AZをまたぐ転送には料金がかかる

同じリージョンの中でも、AZをまたぐデータ転送には料金がかかる。高可用性のために複数のAZに分けるのは大切だが、大量のデータをやり取りする設計では、このAZ間の転送料も見積もりに入れておく。

第4章　問18（2つ選ぶ）

Amazon S3の料金を決める要素として正しいものはどれ？2つ選んで。

  1. ア　保存しているデータの量と選んだストレージクラス
  2. イ　バケット名の文字数
  3. ウ　データを読み書きするリクエストの数
  4. エ　バケットを作った曜日
  5. オ　AWSアカウントのルートユーザーのメールアドレス
答えと解説を見る

正解：ア　保存しているデータの量と選んだストレージクラス
ウ　データを読み書きするリクエストの数

S3の料金は、保存する量とストレージクラス、PUTやGETなどのリクエスト数、データの取り出しや外部への転送量などで決まる。バケット名や作成日、アカウントの情報は料金に関係しない。

第4章　問19

ほとんどアクセスしないが長期間残す必要があるログを、より安く保存したい。料金の考え方として正しいものはどれ？

  1. ア　アクセス頻度の低いデータ向けのストレージクラスは、保存料金が安い代わりに取り出しに料金や時間がかかることがある
  2. イ　ストレージクラスを変えても料金は変わらない
  3. ウ　アクセスが少ないデータほど保存料金が高くなる
  4. エ　ログはAWSの無料の領域に保存されるので料金はかからない
答えと解説を見る

正解：ア　アクセス頻度の低いデータ向けのストレージクラスは、保存料金が安い代わりに取り出しに料金や時間がかかることがある

S3にはアクセス頻度に応じたストレージクラスがあり、まれにしか使わないデータ向けのクラスは保存単価が安い。その代わり、取り出しの料金や取り出しにかかる時間が増えることがあるので、使い方に合わせて選ぶ。

第4章　問20

2025年7月15日以降に作られた新しいAWSアカウントで選べる「無料プラン」の説明として正しいものはどれ？

  1. ア　すべてのAWSサービスを期間の制限なく無料で使える
  2. イ　クレジットを使って一部のサービスを試せ、有料プランにアップグレードしない限り料金は請求されない
  3. ウ　最初の月だけ、どのサービスも無制限に無料で使える
  4. エ　無料プランを選ぶと有料のサポートプランが自動で付く
答えと解説を見る

正解：イ　クレジットを使って一部のサービスを試せ、有料プランにアップグレードしない限り料金は請求されない

新しいアカウントの無料プランでは、もらえるクレジットで対象のサービスを試せ、有料プランにアップグレードしない限り請求は発生しない。使えるサービスは一部に限られ、6か月の期間が過ぎるかクレジットを使い切ると無料プランは終わる。サポートプランは別の契約。
