第3章　問1

JSONやYAMLで書いたテンプレートから、AWSのリソースをまとめて作成・更新できるサービスはどれ？

  1. ア　Amazon CloudWatch
  2. イ　AWS CloudFormation
  3. ウ　AWS Elastic Beanstalk
  4. エ　AWS Systems Manager
答えと解説を見る

正解：イ　AWS CloudFormation

AWS CloudFormation はテンプレートに書いた構成どおりにリソース（スタック）を作るIaCのサービス。CloudWatch は監視、Systems Manager はサーバーの運用管理で、テンプレートからの構築が主目的ではない。

第3章　問2

開発チームが、TypeScriptやPythonなどのふだん使っているプログラミング言語でインフラを定義したいと考えている。どのサービスが最適？

  1. ア　AWS CLI
  2. イ　Amazon API Gateway
  3. ウ　AWS Cloud Development Kit (AWS CDK)
  4. エ　AWS Management Console
答えと解説を見る

正解：ウ　AWS Cloud Development Kit (AWS CDK)

AWS CDK はプログラミング言語でインフラを定義し、内部で CloudFormation のテンプレートに変換してデプロイする。AWS CLI はコマンドで操作する道具で、インフラ全体をコードとして定義する仕組みではない。

第3章　問3

ある開発者は、Webアプリのコードをアップロードするだけで、サーバーの用意・負荷分散・スケーリングをAWSに任せたい。必要ならEC2の設定にも手を入れたい。どのサービスが最適？

  1. ア　AWS Elastic Beanstalk
  2. イ　Amazon Lightsail
  3. ウ　AWS Batch
  4. エ　Amazon EC2 Auto Scaling
答えと解説を見る

正解：ア　AWS Elastic Beanstalk

Elastic Beanstalk はコードを渡すと、EC2・ロードバランサー・Auto Scaling などの環境を自動で作って運用してくれる。裏のリソースは利用者のアカウントにあるので設定も変えられる。EC2 Auto Scaling は台数の調整だけで、アプリの環境全体は作らない。

第3章　問4

数百台のEC2インスタンスとオンプレミスのサーバーに、OSのパッチ適用やコマンドの実行をまとめて行いたい。どのサービスが最適？

  1. ア　AWS CloudFormation
  2. イ　Amazon Inspector
  3. ウ　AWS Config
  4. エ　AWS Systems Manager
答えと解説を見る

正解：エ　AWS Systems Manager

AWS Systems Manager は、EC2やオンプレミスのサーバーをまとめて管理し、パッチ適用やコマンド実行を一括で行える。CloudFormation はリソースの構築、AWS Config は設定の記録と評価が目的。

第3章　問5

運用担当者が、毎晩同じ手順で行っているAWSの作業をシェルスクリプトにして自動で実行したい。最も適した操作方法はどれ？

  1. ア　AWS Management Console
  2. イ　AWS CLI
  3. ウ　AWS Pricing Calculator
  4. エ　Amazon WorkSpaces
答えと解説を見る

正解：イ　AWS CLI

AWS CLI はコマンドでAWSを操作できるので、スクリプトに組み込んで繰り返し実行できる。Management Console はブラウザの画面で手作業する方法で、くり返しの自動化には向かない。

第3章　問6

自社のJavaアプリの中から、S3へのファイル保存やDynamoDBへの書き込みを行いたい。何を使うのが最適？

  1. ア　AWS Elastic Beanstalk
  2. イ　AWS SDK
  3. ウ　AWS Management Console
  4. エ　AWS CloudShell
答えと解説を見る

正解：イ　AWS SDK

AWS SDK は各プログラミング言語からAWSのAPIを呼び出すためのライブラリで、アプリのコードに組み込んで使う。CloudShell やコンソールは人が操作するための道具で、アプリの中からは使わない。

第3章　問7（2つ選ぶ）

インフラをコードで管理する（Infrastructure as Code）利点として正しいものはどれ？2つ選んで。

  1. ア　同じ構成の環境を何度でも同じように作れる
  2. イ　AWSの利用料金が自動的に無料になる
  3. ウ　インフラの変更履歴をバージョン管理できる
  4. エ　リージョンを選ばなくてもよくなる
  5. オ　サーバーのOSのパッチが不要になる
答えと解説を見る

正解：ア　同じ構成の環境を何度でも同じように作れる
ウ　インフラの変更履歴をバージョン管理できる

IaCでは構成をファイルに書くため、開発・本番などの環境を同じように再現でき、Gitなどで変更履歴も管理できる。料金が無くなったり、リージョンやパッチの管理が不要になったりはしない。

第3章　問8

機械学習モデルの学習のために、GPUを搭載したEC2インスタンスを使いたい。どのインスタンスファミリーを選ぶ？

  1. ア　汎用
  2. イ　コンピューティング最適化
  3. ウ　メモリ最適化
  4. エ　高速コンピューティング
答えと解説を見る

正解：エ　高速コンピューティング

高速コンピューティング（Accelerated Computing）はGPUなどのアクセラレーターを積んだインスタンスで、機械学習やグラフィックス処理に向く。コンピューティング最適化は高性能なCPUが中心で、GPUは持たない。

第3章　問9

大量のデータをメモリ上に載せて処理するインメモリデータベースをEC2で動かしたい。どのインスタンスファミリーが最適？

  1. ア　ストレージ最適化
  2. イ　メモリ最適化
  3. ウ　コンピューティング最適化
  4. エ　汎用
答えと解説を見る

正解：イ　メモリ最適化

メモリ最適化インスタンスはCPUに対してメモリが多く、大きなデータをメモリで扱う処理に向く。ストレージ最適化はローカルディスクへの高速な読み書き、コンピューティング最適化はCPUを多く使う処理向け。

第3章　問10

動画のエンコードや科学計算など、CPUの処理能力を多く使うワークロードに最も適したEC2インスタンスファミリーはどれ？

  1. ア　コンピューティング最適化
  2. イ　メモリ最適化
  3. ウ　ストレージ最適化
  4. エ　汎用
答えと解説を見る

正解：ア　コンピューティング最適化

コンピューティング最適化インスタンスは高性能なプロセッサを持ち、CPU負荷の高い処理に向く。汎用はCPU・メモリ・ネットワークのバランス型で、特定の負荷に特化していない。

第3章　問11

OS・設定・インストール済みのソフトウェアを含み、EC2インスタンスを起動するときのひな形になるものはどれ？

  1. ア　EBSスナップショット
  2. イ　セキュリティグループ
  3. ウ　Amazon マシンイメージ（AMI）
  4. エ　インスタンスプロファイル
答えと解説を見る

正解：ウ　Amazon マシンイメージ（AMI）

AMI はインスタンスの起動に必要なOSやソフトウェアをまとめたイメージで、同じ構成のインスタンスを何台でも起動できる。EBSスナップショットはボリュームのバックアップ、セキュリティグループは通信の許可ルール。

第3章　問12

ECサイトのアクセスが昼に増えて夜に減る。負荷に合わせてEC2インスタンスの台数を自動で増減したい。どのサービスが最適？

  1. ア　Amazon EC2 Auto Scaling
  2. イ　Amazon Route 53
  3. ウ　AWS Systems Manager
  4. エ　Amazon CloudFront
答えと解説を見る

正解：ア　Amazon EC2 Auto Scaling

EC2 Auto Scaling は、CPU使用率などの指標やスケジュールに応じてインスタンスの台数を自動で増減する。CloudFront はコンテンツの配信、Route 53 はDNSで、台数の調整はしない。

第3章　問13

Webアプリで、URLのパス（/images や /api など）によってリクエストを別のサーバー群に振り分けたい。どのロードバランサーが最適？

  1. ア　Network Load Balancer
  2. イ　Gateway Load Balancer
  3. ウ　Application Load Balancer
  4. エ　Amazon Route 53
答えと解説を見る

正解：ウ　Application Load Balancer

Application Load Balancer（ALB）はHTTP/HTTPSのレイヤー7で動き、パスやホスト名で振り分けられる。Network Load Balancer はTCP/UDPのレイヤー4で動き、HTTPの中身を見た振り分けはしない。

第3章　問14

オンラインゲームのサーバーで、TCP/UDPの通信を非常に低い遅延で大量にさばきたい。固定のIPアドレスも使いたい。どのロードバランサーが最適？

  1. ア　Amazon API Gateway
  2. イ　Application Load Balancer
  3. ウ　Amazon CloudFront
  4. エ　Network Load Balancer
答えと解説を見る

正解：エ　Network Load Balancer

Network Load Balancer（NLB）はレイヤー4で動き、TCP/UDPを高速・低遅延で処理でき、AZごとに固定IPを持てる。ALB はHTTP/HTTPS向け、API Gateway はAPIの公開・管理のサービス。

第3章　問15

S3に画像がアップロードされたら、サムネイルを自動で作りたい。サーバーの管理はしたくない。どのサービスが最適？

  1. ア　Amazon EC2
  2. イ　Amazon Lightsail
  3. ウ　AWS Lambda
  4. エ　Amazon EMR
答えと解説を見る

正解：ウ　AWS Lambda

AWS Lambda はS3へのアップロードなどのイベントをきっかけにコードを実行するサーバーレスのサービスで、実行した分だけ課金される。EC2 や Lightsail はサーバーを自分で管理する必要がある。

第3章　問16

1回の処理に数時間かかるバッチ処理を AWS Lambda で動かすのが向かない理由として正しいものはどれ？

  1. ア　Lambda はPythonでしか書けないから
  2. イ　Lambda は1回の実行時間に上限（最大15分）があるから
  3. ウ　Lambda はVPCの中で動かせないから
  4. エ　Lambda は使っていない時間も課金されるから
答えと解説を見る

正解：イ　Lambda は1回の実行時間に上限（最大15分）があるから

Lambda の1回の実行は最大15分までなので、数時間かかる処理には AWS Batch や ECS などが向く。Lambda は多くの言語に対応し、VPCにも接続でき、実行していない時間は課金されない。

第3章　問17

コンテナを動かしたいが、EC2インスタンスの用意やパッチ適用などのサーバー管理はしたくない。Amazon ECS や Amazon EKS と組み合わせて使うサービスはどれ？

  1. ア　Amazon ECR
  2. イ　AWS Fargate
  3. ウ　Amazon EC2 Auto Scaling
  4. エ　AWS Elastic Beanstalk
答えと解説を見る

正解：イ　AWS Fargate

AWS Fargate はコンテナ向けのサーバーレスの実行環境で、サーバーを管理せずにコンテナを動かせる。Amazon ECR はコンテナイメージを保存するレジストリで、コンテナを実行する場所ではない。

第3章　問18（2つ選ぶ）

多数のコンテナの起動・停止・配置を管理する（コンテナオーケストレーション）サービスはどれ？2つ選んで。

  1. ア　Amazon ECR
  2. イ　Amazon ECS
  3. ウ　Amazon EBS
  4. エ　Amazon EKS
  5. オ　AWS Glue
答えと解説を見る

正解：イ　Amazon ECS
エ　Amazon EKS

Amazon ECS はAWS独自の、Amazon EKS はKubernetesの、コンテナオーケストレーションのサービス。すでにKubernetesを使っているならEKSが向く。ECR はコンテナイメージの保存場所で、コンテナの実行は管理しない。

第3章　問19

Dockerのコンテナイメージを安全に保存・管理し、ECSやEKSから取り出して使いたい。どのサービスが最適？

  1. ア　Amazon S3 Glacier Deep Archive
  2. イ　AWS Fargate
  3. ウ　Amazon EFS
  4. エ　Amazon ECR
答えと解説を見る

正解：エ　Amazon ECR

Amazon ECR（Elastic Container Registry）はコンテナイメージを保存するマネージドのレジストリ。Fargate はコンテナを実行する環境、EFS はファイル共有のストレージで、イメージ管理の機能はない。

第3章　問20

個人事業主が、小さなWebサイトを月額のわかりやすい料金で手軽に立ち上げたい。サーバー・ストレージ・固定IPがセットになったサービスはどれ？

  1. ア　Amazon Lightsail
  2. イ　Amazon EKS
  3. ウ　AWS Batch
  4. エ　Amazon EC2 専有ホスト
答えと解説を見る

正解：ア　Amazon Lightsail

Amazon Lightsail は仮想サーバー・ストレージ・固定IPなどをまとめた、わかりやすい月額プランで使える簡単なサービス。EKS や専有ホストは、小規模なサイトには大がかりすぎる。
